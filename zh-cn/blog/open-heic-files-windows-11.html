如何在 Windows 11 上打开 HEIC 文件

2026年8月31日 · 阅读约 6 分钟

你把 iPhone 里的照片拷到 Windows 11 电脑上，双击其中一张，结果看到的是空白窗口、一条错误提示，或者一个「要用哪个应用打开」的询问。文件后缀是 .heic，似乎没有任何程序读得懂它。这是苹果设备与 Windows 之间最常见的摩擦之一，好消息是，解决它只需要一分钟。

下面说明这是为什么，以及在 Windows 11 上打开 HEIC 文件的所有可行办法——包括完全无需安装的那一种。

简短版本

Windows 11 只有在你从 Microsoft Store 安装「HEIF 图像扩展」和「HEVC 视频扩展」之后才能打开 HEIC，而后者通常是收费项目。 如果你既不想付费也不想安装任何东西，那就改为转换照片：在 Edge、Chrome 或 Firefox 中打开 HeicQuick（heicquick.com），把 .heic 文件拖到页面上，下载每个 Windows 应用都已经认识的 JPG。转换在你自己的电脑上运行，因此什么都不会被上传。

为什么 Windows 默认打不开 HEIC

自 2017 年起，iPhone 和 iPad 为了节省存储空间，把照片保存为 HEIC（High Efficiency Image Container）。里面的图像用一种叫 HEVC 的编解码器压缩，效率很高，但受专利保护——而正是这个授权问题，构成了 Windows 开箱即用时不解码它的主要原因。

Windows 11 是能显示 HEIC 照片的，但前提是装好了对应的解码组件。在那之前，「照片」应用和文件资源管理器根本不知道该怎么读这个文件。你的照片没有损坏，只是 Windows 还没拿到打开它的钥匙。

你大致有三条路：装上编解码器让 Windows 原生打开 HEIC；把文件转换成 Windows 已经认识的格式；或者用一个什么都不安装的浏览器转换器。我们逐一来看。

方案一：为 Windows 添加 HEIF 编解码器

微软在 Microsoft Store 里把 HEIC 支持拆成了两部分：

  • HEIF 图像扩展——负责 HEIF 容器。
  • HEVC 视频扩展——负责图像本身的压缩，这一项通常是收费的（往往在一美元左右）。另外还有一个「来自设备制造商」的免费版本，部分电脑符合条件。

两者都装好后，Windows「照片」应用和资源管理器的缩略图就会像显示其他照片一样显示 HEIC 图像。试试看：

  1. 打开 Microsoft Store。
  2. 搜索 HEIF 图像扩展 并安装。
  3. 搜索 HEVC 视频扩展 并安装（注意价格）。
  4. 重新打开你的 HEIC 照片——现在应该能在「照片」中显示了。

如果你经常收到 HEIC 文件，并希望它们今后在这台电脑上直接就能用，这是最好的路线。缺点是：涉及一个付费扩展，而且在 Windows 大版本更新之后，这些组件偶尔需要重新安装。

方案二：把文件转换成 JPG 或 PNG

如果你不想买扩展——或者只是需要打开、发邮件或上传这一批照片——把它们转换成通用格式更快，而且免费。JPG 和 PNG 在任何版本的 Windows 上都能直接打开，不需要任何附加组件。

  1. 在任意浏览器（Edge、Chrome 或 Firefox）中打开转换器页面。
  2. 把 .heic 文件拖到页面上——一次拖入整个文件夹也可以。
  3. 下载转换好的 JPG。

就这么简单。JPG 在「照片」应用里瞬间打开，可以直接放进文档，也能上传到任何网站。如果你需要一份用于编辑的无损副本，请改用 HEIC 转 PNG；如果图片是要放到你自己做的网站上，HEIC 转 WebP 生成的文件最小。

你的照片从不离开这台电脑。 转换完全在浏览器内运行——图像在你自己的机器上被解码并重新保存，没有任何东西上传到服务器。这让它即便面对身份证扫描件或医疗照片这类敏感材料也同样安全。

方案三：直接在浏览器里打开

由于上面的转换器本身就在浏览器里运行，你甚至不需要保存任何东西就能快速看一眼 HEIC 文件。把文件拖进主转换器，让它完成解码，图像就会直接显示出来——当你用的是别人的电脑，或者在不允许安装 Store 应用的机器上时，这是一种零安装的预览方式。

该选哪一个？

  • 你在这台电脑上会经常接触 HEIC 文件 → 安装编解码器（方案一），让 Windows 在任何地方都能原生打开它们。
  • 你只是需要这几张照片变成普通格式 → 转换成 JPG（方案二）。免费、即时，结果到哪儿都能用。
  • 你用的是受限或借来的电脑 → 用浏览器转换器（方案三），它什么都不安装。

对大多数偶尔收到 iPhone 照片的人来说，方案二是最舒服的平衡点：不用付费、不用装软件，最后拿到的 JPG 十年后在任何设备上依然打得开。

从源头解决问题

如果这些 HEIC 文件来自你自己的 iPhone 或 iPad，你可以让相机从一开始就拍 JPG：

  1. 在 iPhone 上打开设置 → 相机 → 格式。
  2. 点按兼容性最佳。

此后的新照片都会存成 JPG，传到 Windows 电脑上就能直接打开。代价是文件更大，并失去一些 HEIC 独有的特性，所以很多人索性把相机保持在高效模式，只在转移到 Windows 时转换副本。图库里已有的照片仍然是 HEIC，所以第一次还是得转换它们。

结论

Windows 11 开箱打不开 HEIC，是因为它缺少 HEVC 解码器，而不是因为你的照片有什么问题。想要永久的原生支持，就装上那两个 Store 扩展；不想付费也不想安装，就用几秒钟把文件转成 JPG。两条路都能让你的 iPhone 照片显示在电脑上。
