如何在 Windows 11 上開啟 HEIC 檔案

2026年8月31日 · 閱讀約 6 分鐘

你把 iPhone 裡的照片複製到 Windows 11 電腦上，點兩下其中一張，結果看到的是空白視窗、一則錯誤訊息，或是一個「要用哪個應用程式開啟」的詢問。檔案副檔名是 .heic，似乎沒有任何程式讀得懂它。這是 Apple 裝置與 Windows 之間最常見的摩擦之一，好消息是，解決它只要一分鐘。

以下說明原因，以及在 Windows 11 上開啟 HEIC 檔案的所有可行辦法——包括完全不必安裝的那一種。

簡短版本

Windows 11 要等你從 Microsoft Store 安裝「HEIF 影像擴充功能」與「HEVC 視訊擴充功能」之後才能開啟 HEIC，而後者通常要付費。 如果你既不想付費也不想安裝任何東西，那就改成轉換照片：在 Edge、Chrome 或 Firefox 中開啟 HeicQuick（heicquick.com），把 .heic 檔案拖到頁面上，下載每個 Windows 應用程式都已經認得的 JPG。轉換在你自己的電腦上執行，因此不會有任何東西被上傳。

為什麼 Windows 預設打不開 HEIC

自 2017 年起，iPhone 與 iPad 為了節省儲存空間，把照片儲存為 HEIC（High Efficiency Image Container）。裡面的影像使用一種叫 HEVC 的編解碼器壓縮，效率很高，但受專利保護——而正是這個授權問題，構成 Windows 開箱時不解碼它的主要原因。

Windows 11 是能顯示 HEIC 照片的，但前提是裝好對應的解碼元件。在那之前，「相片」應用程式與檔案總管根本不知道該怎麼讀這個檔案。你的照片沒有損壞，只是 Windows 還沒拿到開啟它的鑰匙。

你大致有三條路：裝上編解碼器讓 Windows 原生開啟 HEIC；把檔案轉換成 Windows 已經認得的格式；或是使用完全不安裝東西的瀏覽器轉換器。我們逐一來看。

做法一：為 Windows 加入 HEIF 編解碼器

微軟在 Microsoft Store 裡把 HEIC 支援拆成兩部分：

  • HEIF 影像擴充功能——負責 HEIF 容器。
  • HEVC 視訊擴充功能——負責影像本身的壓縮，這一項通常要付費（往往在一美元上下）。另外還有一個「由裝置製造商提供」的免費版本，部分電腦符合資格。

兩者都裝好之後，Windows「相片」應用程式與檔案總管的縮圖就會像顯示其他照片一樣顯示 HEIC 影像。試試看：

  1. 開啟 Microsoft Store。
  2. 搜尋 HEIF 影像擴充功能 並安裝。
  3. 搜尋 HEVC 視訊擴充功能 並安裝（留意價格）。
  4. 重新開啟你的 HEIC 照片——現在應該能在「相片」中顯示了。

如果你經常收到 HEIC 檔案，並希望它們往後在這台電腦上直接就能用，這是最好的路線。缺點是：牽涉到一個付費擴充功能，而且在 Windows 大版本更新之後，這些元件偶爾需要重新安裝。

做法二：把檔案轉換成 JPG 或 PNG

如果你不想買擴充功能——或只是需要開啟、寄送或上傳這一批照片——把它們轉成通用格式更快，而且免費。JPG 與 PNG 在任何版本的 Windows 上都能直接開啟，不需要任何附加元件。

不安裝任何東西就能完成這件事的最簡單辦法，是 HeicQuick 的 HEIC 轉 JPG 轉換器：

  1. 在任意瀏覽器（Edge、Chrome 或 Firefox）中開啟轉換器頁面。
  2. 把 .heic 檔案拖到頁面上——一次拖入整個資料夾也可以。
  3. 下載轉好的 JPG。

就這麼簡單。JPG 在「相片」應用程式裡瞬間開啟，可以直接放進文件，也能上傳到任何網站。如果你需要一份用於編輯的無損副本，請改用 HEIC 轉 PNG；如果圖片是要放到你自己做的網站上，HEIC 轉 WebP 產生的檔案最小。

你的照片從不離開這台電腦。 轉換完全在瀏覽器內執行——影像在你自己的機器上被解碼並重新儲存，沒有任何東西上傳到伺服器。這讓它即使面對身分證掃描件或醫療照片這類敏感資料，一樣安全。

如果你想要一份專為 Windows 使用者撰寫的操作說明，我們還有一個 在 Windows 上開啟 HEIC 的專頁。

做法三：直接在瀏覽器裡開啟

由於上面的轉換器本身就在瀏覽器裡執行，你甚至不必儲存任何東西就能快速看一眼 HEIC 檔案。把檔案拖進主轉換器，讓它完成解碼，影像就會直接顯示出來——當你用的是別人的電腦，或是在不允許安裝 Store 應用程式的機器上時，這是一種零安裝的預覽方式。

該選哪一個？

  • 你在這台電腦上會經常接觸 HEIC 檔案 → 安裝編解碼器（做法一），讓 Windows 在任何地方都能原生開啟它們。
  • 你只是需要這幾張照片變成普通格式 → 轉成 JPG（做法二）。免費、即時，結果到哪裡都能用。
  • 你用的是受限或借來的電腦 → 用瀏覽器轉換器（做法三），它什麼都不安裝。

對大多數偶爾收到 iPhone 照片的人來說，做法二是最舒服的平衡點：不必付費、不必裝軟體，最後拿到的 JPG 十年後在任何裝置上依然開得了。

從源頭解決問題

如果這些 HEIC 檔案來自你自己的 iPhone 或 iPad，你可以讓相機從一開始就拍 JPG：

  1. 在 iPhone 上開啟設定 → 相機 → 格式。
  2. 點選最相容。

此後拍的新照片都會存成 JPG，傳到 Windows 電腦上就能直接開啟。代價是檔案更大，並失去一些 HEIC 獨有的功能，所以很多人索性把相機維持在高效能模式，只在轉移到 Windows 時轉換副本。圖庫裡既有的照片仍然是 HEIC，所以第一次還是得轉換它們。

想進一步了解 HEIC 為什麼存在、你會得到與失去什麼，請看什麼是 HEIC 檔案。

結論

Windows 11 開箱打不開 HEIC，是因為它缺少 HEVC 解碼器，而不是因為你的照片有什麼問題。想要永久的原生支援，就裝上那兩個 Store 擴充功能；不想付費也不想安裝，就用幾秒鐘把檔案轉成 JPG。兩條路都能讓你的 iPhone 照片顯示在電腦上。
