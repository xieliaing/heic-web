Short answer

To split a multi-page PDF without uploading it, open HeicQuick at heicquick.com/pdf, drop the file on the page, and pick what you want out of it: single-page PDFs (one PDF per page, lossless) or JPEG pictures (one image per page, at 96, 150 or 300 DPI). Press Split and the pages appear as downloads — individually, or bundled in a ZIP. To combine files instead, drop several PDFs, choose One merged PDF, set the order with the ▲ ▼ arrows and press Merge. The work is done by JavaScript inside the page, so the PDFs are read straight off your disk and never sent to a server.

Three things it does, and when to use each

Single-page PDFs Each page is copied into its own PDF with its text, fonts and vector artwork intact. Nothing is re-encoded, so the output stays selectable, searchable and sharp at any zoom. Use this to send one page of a contract, to split a scanned batch into separate records, or to upload a single page to a portal that rejects multi-page files.
JPEG pictures Each page is drawn onto a canvas and saved as a photo-style image. Use this when something needs a picture rather than a document: a forum or chat app that will not preview a PDF, a slide deck, an image upload field, or a print shop that asked for images. Pick 300 DPI for print, 150 DPI for most on-screen use, and 96 DPI when small files matter more than detail.
One merged PDF Every page of every file is copied, in list order, into a single PDF. Text and vector artwork stay intact, and each page is scaled to fit the page size of the first PDF and centred, so a mix of A4, Letter and landscape pages comes out as one consistently sized document. Use this to send a contract with its appendices as one file, or to meet an upload form that accepts a single PDF.

Why use this tool?

  • Nothing is uploaded — the pages are extracted and rendered on your own machine. A payslip, a passport scan or a signed contract never leaves the device, and the tool keeps working with the network off once the page has loaded.
  • No signup, no page limit, no watermark — split as many documents, as often, as you like.
  • Batch friendly — drop several PDFs at once; each one gets its own folder in the ZIP.
  • Lossless where it counts — the single-page PDF path copies page objects rather than re-printing them, so text stays text.
  • Works everywhere — Chrome, Edge, Safari and Firefox, on phones, tablets and computers.

Frequently asked questions

How do I split a PDF into separate pages without uploading it?

Drop the PDF on this page, choose Single-page PDFs, and press Split. Each page is written out as its own PDF; download them one by one or take the whole set as a ZIP. The code runs in your browser, so the document is never sent anywhere.

Can I turn each page into a JPEG image?

Yes — choose JPEG pictures. Every page is rendered to an image at the resolution you select, with an adjustable quality slider. That is the option to use when a site or app wants a picture rather than a document.

How do I merge several PDFs into one?

Drop the PDFs on this page, choose One merged PDF, and use the ▲ ▼ arrows to put the files in order. Press Merge and a single PDF is ready to download. Every page is fitted to the page size of the first PDF, keeping its proportions, so the first file decides the size of the whole document.

Does splitting a PDF reduce quality?

Not in PDF mode: pages are copied with their original text, fonts and vectors, so there is no re-encoding at all. JPEG mode is different by nature — the page is turned into pixels, so choose 300 DPI if the result will be printed.

Is there a limit on pages or file size?

None from the site. The real limit is your device's memory, since each page produced is held in the browser until you download it. A few hundred pages is comfortable on a laptop. On a phone, prefer 150 DPI for very long documents.

Can it split or merge a password-protected PDF?

No, and it says so rather than producing broken pages. Open the file in a PDF reader, save an unlocked copy, then use that copy here.

Where do the split files go?

Into your normal downloads folder, only when you click a download link or the ZIP button. Until then they exist solely in the browser tab, and closing the tab discards them.
