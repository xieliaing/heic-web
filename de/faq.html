🖼️ HEIC-Bildkonvertierung

Was ist eine HEIC-Datei?

HEIC (High Efficiency Image Container) ist das Standard-Fotoformat auf iPhones und iPads seit iOS 11. Es bietet bei ähnlicher Qualität eine bessere Komprimierung als JPEG, wird jedoch auf Windows, Websites oder älterer Software nicht weit verbreitet unterstützt — weshalb die Konvertierung in JPG oder PNG oft notwendig ist.

Werden meine Fotos irgendwo hochgeladen?

Nein. Dieser Konverter läuft vollständig in Ihrem Webbrowser mit einer WebAssembly-Version von libheif. Ihre Dateien werden niemals an einen Server gesendet. Sie können die Internetverbindung nach dem Laden der Seite sogar trennen, und es wird trotzdem funktionieren.

Gibt es eine Dateigrößen- oder Anzahlbeschränkung?

Es gibt keine harte Begrenzung, aber da die Konvertierung den Arbeitsspeicher Ihres Computers verwendet, können sehr große Dateien (100+ MB) oder sehr große Stapel Ihren Browser verlangsamen. Für beste Ergebnisse konvertieren Sie Dateien in Stapeln von 10–20 auf einmal.

JPG, PNG oder WebP — welches soll ich wählen?

Wählen Sie JPEG für Fotos, die Sie teilen oder per E-Mail senden möchten — es wird überall unterstützt und erzeugt kleine Dateien. Wählen Sie PNG, wenn Sie verlustfreie Qualität oder Transparenz benötigen. Wählen Sie WebP, wenn Sie auf eine Website hochladen und die kleinste Dateigröße bei gleicher Qualität wünschen (typischerweise 25–35% kleiner als JPEG). Für die meisten iPhone-Fotos ist JPEG die sichere Standardwahl.

Funktioniert das auf iPhone oder Android?

Ja. Öffnen Sie diese Seite in Safari (iPhone) oder Chrome (Android), tippen Sie auf den Upload-Bereich, wählen Sie Fotos aus Ihrer Kamerarolle, konvertieren Sie und speichern Sie das Ergebnis zurück auf Ihr Gerät.

🎬 Videoformat-Konvertierung

Muss ich FFmpeg auf meinem Computer installieren?

Nein. Der Konverter nutzt eine WebAssembly-Version von FFmpeg, die die Seite herunterlädt und in der Sandbox des Browsers ausführt — genauso, wie Ihr Browser jede JavaScript-Bibliothek ausführt. Es wird nichts installiert, es werden keine Berechtigungen angefordert, und ein bereits auf Ihrem Rechner vorhandenes FFmpeg wird weder gesehen noch verwendet.

Warum gibt es beim ersten Mal einen einmaligen Download?

Die Video-Engine ist etwa 31 MB groß. Sie wird erst geladen, wenn Sie tatsächlich eine Datei hinzufügen, und danach vom Browser zwischengespeichert — jede weitere Konvertierung startet sofort, auch offline.

Werden meine Videos irgendwohin hochgeladen?

Nein. Alles geschieht lokal in Ihrem Browser. Sie können die Internetverbindung trennen, sobald die Engine geladen ist, und trotzdem weiter konvertieren.

Warum ist das langsamer als ein Desktop-Programm?

WebAssembly läuft hier auf einem einzigen CPU-Kern und kann die dedizierte Video-Hardware Ihres Rechners nicht nutzen. Rechnen Sie bei einer vollständigen Neukodierung also mit etwa Echtzeit oder langsamer. Zwei Dinge beschleunigen das deutlich: die Originalauflösung beibehalten, wenn die Quelle bereits H.264 ist (dann wird remuxt statt neu kodiert), und die Ausgabeauflösung verringern.

Gibt es eine Dateigrößenbeschränkung?

Die Engine ist 32-Bit, adressiert also höchstens rund 2 GB Speicher und muss Eingabe und Ausgabe gleichzeitig halten. Dateien über etwa 1 GB schlagen fehl; alles über 300 MB wird langsam. Konvertieren Sie lange Aufnahmen mit 720p oder weniger.

Kann H.265/HEVC oder AV1 ausgegeben werden?

Derzeit nicht. Beide können gelesen werden, aber die WebAssembly-Version enthält keinen HEVC-Encoder, und AV1-Kodierung wäre hier zu langsam. MP4 mit H.264 ist ohnehin das kompatibelste Ziel — es läuft praktisch auf jedem Gerät der letzten 15 Jahre.
