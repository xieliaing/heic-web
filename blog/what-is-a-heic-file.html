What Is a HEIC File, and Why Does My iPhone Use It?

July 18, 2026 · 4 min read

If you've ever AirDropped a photo from your iPhone to a Windows PC — or emailed one to a friend on Android — you may have run into a file ending in .heic that simply won't open. It's one of the most common questions we hear, so let's clear it up: what is a HEIC file, why does your iPhone create them, and what should you do when something can't read one?

The short answer

HEIC stands for High Efficiency Image Container. It's the file format Apple has used by default for iPhone and iPad photos since 2017 (iOS 11). Under the hood it stores images using HEIF (High Efficiency Image Format), a modern standard built on the same compression technology as HEVC video.

In plain terms: a HEIC file is just a photo — the same kind of picture a JPG holds — but saved in a newer, more efficient way.

Why did Apple switch to HEIC?

There's one headline reason: file size.

A HEIC photo is typically about half the size of the same photo saved as a JPG, with no visible loss in quality. On a phone where you might shoot thousands of pictures, that adds up fast — you can fit roughly twice as many photos in the same storage.

But smaller files aren't the only benefit. HEIC also supports things the decades-old JPEG format never could:

  • 16-bit color (versus JPEG's 8-bit), for smoother gradients and better editing headroom
  • Transparency, like a PNG
  • Multiple images in one file — this is how Live Photos and burst shots are stored
  • Depth maps and edits stored alongside the original, non-destructively

So HEIC isn't just "a smaller JPG." It's a genuinely more capable format.

Then why is it such a hassle?

The catch is compatibility. JPG is understood by essentially everything made in the last 30 years. HEIC is newer, so support is still catching up:

  • Windows doesn't open HEIC out of the box on older versions (you can add support, but it's an extra step).
  • Android phones and many web apps still expect JPG or PNG.
  • Older software — some photo editors, printing services, and web upload forms — reject HEIC entirely.

That's why a photo that looks perfectly normal on your iPhone can show up as an unopenable file the moment it lands somewhere else.

How to open or convert a HEIC file

You have a few options, depending on what you need.

Option 1: Change your iPhone's camera setting

If you'd rather your iPhone just save JPGs going forward, you can switch it:

  1. Open Settings → Camera → Formats
  2. Choose Most Compatible instead of High Efficiency

Your phone will now capture JPGs. The trade-off is larger files and losing the extra HEIC features above. This only affects new photos — it won't convert the ones you've already taken.

The bottom line

A HEIC file is a normal photo saved in Apple's modern, space-saving format. It's not broken or corrupted — it's just newer than some of the apps and devices trying to open it. When you hit a wall, converting to JPG (or PNG/WebP) takes seconds and solves the problem everywhere.
