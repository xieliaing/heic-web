How to Open HEIC Files on Windows 11

August 17, 2026 · 5 min read

You copied a batch of photos from your iPhone to your Windows 11 PC, double-clicked one, and got a blank Photos window, an error, or a prompt to find an app that can open it. The file has a .heic extension, and Windows isn't sure what to do with it. This is one of the most common friction points between Apple devices and Windows — and the good news is it's easy to solve.

Here are the three practical ways to open HEIC files on Windows 11, from the quickest to the most involved.

Why HEIC doesn't just open on Windows

Since 2017, iPhones and iPads have saved photos as HEIC (High Efficiency Image Container) by default. The files are roughly half the size of a JPG at the same visual quality, which is why Apple adopted them. The trade-off is compatibility: HEIC uses a compression method called HEVC (also known as H.265), and Windows doesn't include an HEVC decoder in every installation.

That's the real reason a .heic file can look "broken" on a PC. The photo itself is perfectly fine — Windows simply may not have the piece of software it needs to read that particular compression. Once you give it the decoder (or hand it a format it already understands), the same photo opens instantly.

Option 1: Convert the file — the no-install fix

If you just want to see the photo, or you need to use it somewhere else anyway, the fastest path is to convert it to JPG. JPG opens on every version of Windows ever made, with no extensions, no Microsoft Store, and no settings to change.

  1. Open the HEIC to JPG converter in your browser (Edge, Chrome, or Firefox all work).
  2. Drag your .heic files onto the page — you can do a whole batch at once.
  3. Download the JPGs and open them in Windows Photos as normal.

Because the conversion runs entirely inside your browser, your photos never get uploaded to a server. Nothing leaves your PC, there's no account, and it works the same whether it's one holiday snap or two hundred. This is the option most people want, because the JPG is usually the thing you actually need — to email it, print it, or upload it to a website.

Option 2: Install the official Windows extensions

If you want Windows to open .heic files natively — so double-clicking one just works in the Photos app forever — you can install Microsoft's codec packages from the Microsoft Store.

There are two pieces:

  • HEIF Image Extensions — free. This teaches Windows how to read the HEIF container (the "box" the image sits in).
  • HEVC Video Extensions — this provides the actual HEVC decoder that turns the compressed data into a picture. Microsoft charges a small fee (commonly $0.99) for the general version in the Store. Some PCs from certain manufacturers can install a free "from Device Manufacturer" edition instead, if your hardware qualifies.

To install them, open the Microsoft Store, search for "HEIF Image Extensions," and install it. If your photos still won't render afterward, you also need the HEVC decoder — search for "HEVC Video Extensions."

Once both are in place, HEIC files open in the Photos app, show thumbnails in File Explorer, and preview normally. The catch is that HEVC is patent-encumbered, which is exactly why the decoder isn't free for everyone — and it's why a lot of people skip this step and just convert instead.

Option 3: Use a photo app that reads HEIC on its own

Some third-party image viewers and editors bundle their own HEIC support, so they don't rely on the Windows codecs at all. If you already use a full photo editor — for example one that opens RAW files from a camera — check whether it lists HEIC or HEIF among its supported formats. When it does, you can open the file directly without touching the Microsoft Store.

This is a reasonable route if you edit photos regularly. For a one-off "I just need to see this picture," it's more setup than it's worth compared to a quick conversion.

Which option should you pick?

  • Just need to view or use one photo? Convert it to JPG. No install, no cost, done in seconds.
  • Copying iPhone photos to a PC all the time? Installing the Windows extensions makes .heic open natively so you never think about it again.
  • A serious photo editor? Check if your app already supports HEIC before installing anything.

Prefer to stop the problem at the source

You can also tell your iPhone to shoot in the more compatible format from the start. Go to Settings → Camera → Formats and choose Most Compatible — new photos will be saved as JPG, which opens on Windows with zero extra steps. This only affects future photos; anything already in your library stays HEIC, so you'll still convert those when you need them.

The bottom line

Windows 11 can open HEIC — it just doesn't always come ready to. You can pay a small fee for Microsoft's HEVC decoder and make it native, lean on a photo editor that reads the format, or skip all of that and convert your files to a format Windows already loves.
