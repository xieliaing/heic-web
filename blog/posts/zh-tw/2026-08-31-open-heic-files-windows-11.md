你把 iPhone 裡的照片複製到 Windows 11 電腦上，點兩下其中一張，結果看到的是空白視窗、一則錯誤訊息，或是一個「要用哪個應用程式開啟」的詢問。檔案副檔名是 `.heic`，似乎沒有任何程式讀得懂它。這是 Apple 裝置與 Windows 之間最常見的摩擦之一，好消息是，解決它只要一分鐘。

以下說明原因，以及在 Windows 11 上開啟 HEIC 檔案的所有可行辦法——包括完全不必安裝的那一種。

## 簡短版本

**Windows 11 要等你從 Microsoft Store 安裝「HEIF 影像擴充功能」與「HEVC 視訊擴充功能」之後才能開啟 HEIC，而後者通常要付費。** 如果你既不想付費也不想安裝任何東西，那就改成轉換照片：在 Edge、Chrome 或 Firefox 中開啟 **HeicQuick**（heicquick.com），把 `.heic` 檔案拖到頁面上，下載每個 Windows 應用程式都已經認得的 JPG。轉換在你自己的電腦上執行，因此不會有任何東西被上傳。

## 為什麼 Windows 預設打不開 HEIC

自 2017 年起，iPhone 與 iPad 為了節省儲存空間，把照片儲存為 **HEIC**（High Efficiency Image Container）。裡面的影像使用一種叫 HEVC 的編解碼器壓縮，效率很高，但受專利保護——而正是這個授權問題，構成 Windows 開箱時不解碼它的主要原因。

Windows 11 *是能*顯示 HEIC 照片的，但前提是裝好對應的解碼元件。在那之前，「相片」應用程式與檔案總管根本不知道該怎麼讀這個檔案。你的照片沒有損壞，只是 Windows 還沒拿到開啟它的鑰匙。

你大致有三條路：裝上編解碼器讓 Windows 原生開啟 HEIC；把檔案轉換成 Windows 已經認得的格式；或是使用完全不安裝東西的瀏覽器轉換器。我們逐一來看。

## 做法一：為 Windows 加入 HEIF 編解碼器

微軟在 Microsoft Store 裡把 HEIC 支援拆成兩部分：

- **HEIF 影像擴充功能**——負責 HEIF 容器。
- **HEVC 視訊擴充功能**——負責影像本身的壓縮，這一項通常要付費（往往在一美元上下）。另外還有一個「由裝置製造商提供」的免費版本，部分電腦符合資格。

兩者都裝好之後，Windows「相片」應用程式與檔案總管的縮圖就會像顯示其他照片一樣顯示 HEIC 影像。試試看：

1. 開啟 **Microsoft Store**。
2. 搜尋 **HEIF 影像擴充功能** 並安裝。
3. 搜尋 **HEVC 視訊擴充功能** 並安裝（留意價格）。
4. 重新開啟你的 HEIC 照片——現在應該能在「相片」中顯示了。

如果你經常收到 HEIC 檔案，並希望它們往後在這台電腦上*直接就能用*，這是最好的路線。缺點是：牽涉到一個付費擴充功能，而且在 Windows 大版本更新之後，這些元件偶爾需要重新安裝。

## 從源頭解決問題

如果這些 HEIC 檔案來自*你自己的* iPhone 或 iPad，你可以讓相機從一開始就拍 JPG：

1. 在 iPhone 上開啟**設定 → 相機 → 格式**。
2. 點選**最相容**。

此後拍的新照片都會存成 JPG，傳到 Windows 電腦上就能直接開啟。代價是檔案更大，並失去一些 HEIC 獨有的功能，所以很多人索性把相機維持在**高效能**模式，只在轉移到 Windows 時轉換副本。圖庫裡既有的照片仍然是 HEIC，所以第一次還是得轉換它們。
