You copied some photos off your iPhone, double-clicked one on your Windows 11 PC, and got a blank window, an error, or a prompt asking which app to use. The file has a `.heic` extension and nothing seems to read it. This is one of the most common friction points between Apple devices and Windows, and the good news is that it takes only a minute to fix.

Here's why it happens and every practical way to open a HEIC file on Windows 11 — including the option that needs no installation at all.

## Why HEIC won't open on Windows by default

Since 2017, iPhones and iPads have saved photos as **HEIC** (High Efficiency Image Container) to save storage space. The image inside is compressed with a codec called HEVC, which is efficient but patent-encumbered — and that licensing is the main reason Windows doesn't decode it out of the box.

Windows 11 *can* display HEIC photos, but only once the right decoding components are installed. Until then, the Photos app and File Explorer simply don't know how to read the file. Your photo isn't corrupted; Windows just doesn't have the key to open it yet.

You have three broad choices: add the codecs so Windows opens HEIC natively, convert the files to a format Windows already understands, or use a browser-based converter that needs no install. Let's go through each.

## Option 1: Add the HEIF codecs to Windows

Microsoft splits HEIC support into two pieces in the Microsoft Store:

- **HEIF Image Extensions** — handles the HEIF container.
- **HEVC Video Extensions** — handles the actual image compression, and this one is typically a paid item (often around a dollar). There is also a free "from Device Manufacturer" variant that some PCs qualify for.

Once both are installed, the Windows Photos app and File Explorer thumbnails start showing HEIC images like any other photo. To try it:

1. Open the **Microsoft Store**.
2. Search for **HEIF Image Extensions** and install it.
3. Search for **HEVC Video Extensions** and install it (note the price).
4. Reopen your HEIC photo — it should now display in Photos.

This is the best route if you regularly receive HEIC files and want them to *just work* on your PC going forward. The downside: it involves a paid extension, and the components occasionally need reinstalling after major Windows updates.

- **You'll deal with HEIC files often on this PC** → install the codecs (Option 1) so Windows opens them natively everywhere.

## Stop the problem at the source

If the HEIC files are coming from *your own* iPhone or iPad, you can switch the camera to shoot JPG from the start:

1. On the iPhone, open **Settings → Camera → Formats**.
2. Tap **Most Compatible**.

New photos will save as JPG, which lands on your Windows PC ready to open. The trade-off is larger files and losing some HEIC-only features, so many people leave the camera on **High Efficiency** for the storage savings and just convert copies when moving them to Windows. Existing photos in your library stay HEIC, so you'll still convert those the first time.
