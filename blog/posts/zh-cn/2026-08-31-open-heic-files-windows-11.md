你把 iPhone 里的照片拷到 Windows 11 电脑上，双击其中一张，结果看到的是空白窗口、一条错误提示，或者一个「要用哪个应用打开」的询问。文件后缀是 `.heic`，似乎没有任何程序读得懂它。这是苹果设备与 Windows 之间最常见的摩擦之一，好消息是，解决它只需要一分钟。

下面说明这是为什么，以及在 Windows 11 上打开 HEIC 文件的所有可行办法——包括完全无需安装的那一种。

## 简短版本

**Windows 11 只有在你从 Microsoft Store 安装「HEIF 图像扩展」和「HEVC 视频扩展」之后才能打开 HEIC，而后者通常是收费项目。** 如果你既不想付费也不想安装任何东西，那就改为转换照片：在 Edge、Chrome 或 Firefox 中打开 **HeicQuick**（heicquick.com），把 `.heic` 文件拖到页面上，下载每个 Windows 应用都已经认识的 JPG。转换在你自己的电脑上运行，因此什么都不会被上传。

## 为什么 Windows 默认打不开 HEIC

自 2017 年起，iPhone 和 iPad 为了节省存储空间，把照片保存为 **HEIC**（High Efficiency Image Container）。里面的图像用一种叫 HEVC 的编解码器压缩，效率很高，但受专利保护——而正是这个授权问题，构成了 Windows 开箱即用时不解码它的主要原因。

Windows 11 *是能*显示 HEIC 照片的，但前提是装好了对应的解码组件。在那之前，「照片」应用和文件资源管理器根本不知道该怎么读这个文件。你的照片没有损坏，只是 Windows 还没拿到打开它的钥匙。

你大致有三条路：装上编解码器让 Windows 原生打开 HEIC；把文件转换成 Windows 已经认识的格式；或者用一个什么都不安装的浏览器转换器。我们逐一来看。

## 方案一：为 Windows 添加 HEIF 编解码器

微软在 Microsoft Store 里把 HEIC 支持拆成了两部分：

- **HEIF 图像扩展**——负责 HEIF 容器。
- **HEVC 视频扩展**——负责图像本身的压缩，这一项通常是收费的（往往在一美元左右）。另外还有一个「来自设备制造商」的免费版本，部分电脑符合条件。

两者都装好后，Windows「照片」应用和资源管理器的缩略图就会像显示其他照片一样显示 HEIC 图像。试试看：

1. 打开 **Microsoft Store**。
2. 搜索 **HEIF 图像扩展** 并安装。
3. 搜索 **HEVC 视频扩展** 并安装（注意价格）。
4. 重新打开你的 HEIC 照片——现在应该能在「照片」中显示了。

如果你经常收到 HEIC 文件，并希望它们今后在这台电脑上*直接就能用*，这是最好的路线。缺点是：涉及一个付费扩展，而且在 Windows 大版本更新之后，这些组件偶尔需要重新安装。

- **你在这台电脑上会经常接触 HEIC 文件** → 安装编解码器（方案一），让 Windows 在任何地方都能原生打开它们。

## 从源头解决问题

如果这些 HEIC 文件来自*你自己的* iPhone 或 iPad，你可以让相机从一开始就拍 JPG：

1. 在 iPhone 上打开**设置 → 相机 → 格式**。
2. 点按**兼容性最佳**。

此后的新照片都会存成 JPG，传到 Windows 电脑上就能直接打开。代价是文件更大，并失去一些 HEIC 独有的特性，所以很多人索性把相机保持在**高效**模式，只在转移到 Windows 时转换副本。图库里已有的照片仍然是 HEIC，所以第一次还是得转换它们。
